## Featured Project

🎵 **[Saavan](https://saavan.online)** — A public Discord music bot that supports YouTube, Spotify, Apple Music, Deezer, JioSaavn, and more. Built with TypeScript, Seyfert, Hoshimi, Lavalink, MongoDB & Docker.
Features include premium audio quality, real-time synced lyrics, audio filters, autoplay, 24/7 mode, customizable bot profiles, and full slash command support. Open for anyone to invite.
